# Deep Learning to Discover Coordinates for Dynamics

Learn system dynamics in latent space variational autoencoders.
Project for the course Complex Adaptive Systems, Radboud University Nijmegen.

## Architecture
- Constrained Autoencoders

## Data
- Simulated dynamical system, like a Lorentz attractor or similar
